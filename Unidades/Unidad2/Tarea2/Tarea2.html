Tarea – Simulación del Juego de Dulces

INTRODUCCIÓN

Este trabajo presenta una simulación estocástica del juego realizado en clase, donde se modela un sistema cooperativo basado en intercambio de caramelos. El objetivo consiste en generar recompensas mediante reglas de combinación controladas por probabilidad y disponibilidad de recursos.

El ejercicio permite aplicar conceptos centrales de programación numérica, tales como generación aleatoria, bucles iterativos, manipulación de estructuras de datos, control de flujo y simulación dinámica.

PLANTEAMIENTO DEL PROBLEMA

Descripción general

Se cuenta con N jugadores. Cada uno recibe al inicio dos dulces aleatorios del tipo A, B o C. El objetivo es obtener D recompensas finales, utilizando reglas de combinación entre los recursos.

Reglas del sistema

  • Regla Premium: Si hay 2A, 2B y 2C se generan dos D y se agrega un dulce extra aleatorio.
  • Regla Básica: Si hay al menos 1A, 1B y 1C se genera un D.
  • Regla Inversa: Si no hay combinaciones pero sí recompensas D, se intercambia 1D por 3 dulces.

Condición final

El proceso concluye si se obtiene una recompensa D por cada jugador, si se alcanza el límite de iteraciones o si no quedan movimientos posibles.

CÓDIGO EN R

A continuación se presenta la implementación completa del juego utilizando el lenguaje R: 

# SIMULACION: JUEGO DE INTERCAMBIO DE DULCES
juego_dulces <- function(jugadores = 4, max_iter = 100000) {

  dulce_random <- function() sample(c("A","B","C"),1)

  quitar_combo <- function(pool) {
    for (tipo in c("A","B","C")) {
      pos <- match(tipo , pool)
      if (!is.na(pos)) pool <- pool[-pos]
    }
    return(pool)
  }

  quitar_n <- function(pool , tipo , n) {
    pos <- which(pool == tipo)
    if (length(pos) >= n) pool <- pool[-pos[1:n]]
    return(pool)
  }

  set.seed(as.integer(Sys.time()))
  pool <- replicate(jugadores * 2, dulce_random ())
  D <- 0

  iter <- 0
  while (iter < max_iter && D < jugadores) {
    iter <- iter + 1
    cambio <- FALSE

    a <- sum(pool == "A")
    b <- sum(pool == "B")
    c <- sum(pool == "C")

    combos_dobles <- min(floor(a/2), floor(b/2), floor(c/2))
    while (combos_dobles > 0) {
      pool <- quitar_n(pool , "A", 2)
      pool <- quitar_n(pool , "B", 2)
      pool <- quitar_n(pool , "C", 2)
      D <- D + 2
      pool <- c(pool , dulce_random())
      cambio <- TRUE
      combos_dobles <- combos_dobles - 1
    }

    combos_simples <- min(a, b, c)
    while (combos_simples > 0) {
      pool <- quitar_combo(pool)
      D <- D + 1
      cambio <- TRUE
      combos_simples <- combos_simples - 1
    }

    if (!cambio && D > 0) {
      D <- D - 1
      pool <- c(pool , replicate (3, dulce_random()))
      cambio <- TRUE
    }

    if (!cambio && D == 0 && !all(c("A","B","C") %in% pool)) break
  }

  return(list(D = D, iter = iter, exito = (D >= jugadores)))
}

juego_dulces(4)
