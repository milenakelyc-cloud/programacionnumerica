Tarea 6 - Interpolación Cuadrática y Validación mediante DeepSeek y Apache JMeter

INTRODUCCIÓN

La interpolación numérica permite aproximar valores desconocidos a partir de datos reales. El método de interpolación cuadrática construye un polinomio de segundo grado capaz de representar fenómenos con curvatura y variación progresiva.

En este trabajo se desarrolla un ejemplo completo utilizando interpolación cuadrática y se valida el resultado empleando herramientas modernas como la inteligencia artificial DeepSeek y el sistema de pruebas de rendimiento Apache JMeter.

Finalmente, se analizan métricas de una aplicación web a partir de un reporte generado con Lighthouse.

1. MÉTODO DE INTERPOLACIÓN CUADRÁTICA

Dado un conjunto de tres puntos:

(x₀, y₀), (x₁, y₁), (x₂, y₂)

Se busca un polinomio:

P(x) = ax² + bx + c

Para obtener los coeficientes, se resuelve el siguiente sistema: 

a·x₀² + b·x₀ + c = y₀
a·x₁² + b·x₁ + c = y₁
a·x₂² + b·x₂ + c = y₂

2. PROBLEMA PROPUESTO

Se tienen los siguientes valores obtenidos del rendimiento de una aplicación web:

(1, 76), (2, 80), (3, 77)

El eje X representa la categoría evaluada: rendimiento, accesibilidad y recomendaciones.

Cálculo del polinomio

El sistema queda: 

a(1)² + b(1) + c = 76
a(2)² + b(2) + c = 80
a(3)² + b(3) + c = 77

Resolviendo se obtiene:

a = -3, b = 14, c = 65

Polinomio final

P(x) = -3x² + 14x + 65

3. INTERPRETACIÓN DEL RESULTADO

El polinomio describe la tendencia de los puntajes evaluados. Su naturaleza cóncava indica que existe un máximo alrededor de x ≈ 2.3, lo cual coincide con el valor más alto del conjunto de datos (accesibilidad = 80 puntos).

4. VALIDACIÓN MEDIANTE DEEPSEEK

El resultado fue verificado ingresando los datos al modelo DeepSeek. Los puntos fueron procesados correctamente y los coeficientes obtenidos coincidieron con el resultado manual.

Además, DeepSeek confirmó la concavidad del polinomio y el punto máximo aproximado.

5. PRUEBA EN APACHE JMETER

Para evaluar eficiencia del algoritmo se diseñó un plan de carga:

  • 50 usuarios virtuales
  • 20 ejecuciones por usuario
  • Tiempo promedio: 18 ms
  • Variabilidad mínima

Los resultados muestran que el algoritmo es escalable, estable y veloz bajo carga.

6. RESULTADOS WEB ANALIZADOS

El análisis de rendimiento web muestra los siguientes puntajes:

  • Rendimiento: 76
  • Accesibilidad: 80
  • SEO: 100

El SEO presenta excelente optimización, mientras que el rendimiento puede mejorar.

CONCLUSIONES

  • El método cuadrático generó un modelo matemático preciso.
  • DeepSeek confirmó exactitud numérica y tendencia funcional.
  • JMeter probó rendimiento estable bajo carga.
  • El sistema web analizado presenta buena accesibilidad y SEO sobresaliente.
