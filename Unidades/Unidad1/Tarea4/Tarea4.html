Tarea 4 – Método de Bisección

INTRODUCCIÓN

El método de bisección es una técnica numérica utilizada para encontrar raíces de funciones continuas. Se basa en el Teorema del Valor Intermedio, el cual garantiza la existencia de una raíz en un intervalo cuando la función cambia de signo. Es un método simple, seguro y ampliamente utilizado en el análisis numérico.

MARCO TEÓRICO

El proceso consiste en dividir repetidamente un intervalo [a, b] a la mitad hasta encontrar un punto donde la función sea cercana a cero. El método asegura convergencia siempre que exista cambio de signo.

Criterios de parada más comunes:
• Error absoluto menor a una tolerancia.
• Valor de función cercano a 0.
• Máximo de iteraciones.

IMPORTANCIA DE LA VISUALIZACIÓN

Graficar la función ayuda a identificar raíces, seleccionar intervalos adecuados, validar continuidad y evitar errores. Es una etapa clave antes de aplicar el método.

IMPLEMENTACIÓN EN PYTHON

El programa desarrollado permite:
1. Ingresar una función matemática libremente.
2. Graficarla dentro de un rango seleccionado.
3. Verificar cambio de signo.
4. Ejecutar el método de bisección paso a paso.
5. Mostrar resultados en formato tabular.

CÓDIGO


import numpy as np
import matplotlib.pyplot as plt

print("Ejemplos: x**3-x-1 | x**2-4 | np.cos(x)-x")
func_str = input("\nIngrese funcion f(x): ")

def f(x):
    return eval(func_str, {"np": np, "x": x})

xmin = float(input("Valor minimo de x: "))
xmax = float(input("Valor maximo de x: "))

x = np.linspace(xmin, xmax, 400)
y = f(x)

plt.plot(x, y)
plt.axhline(0, color='black')
plt.axvline(0, color='black')
plt.grid()
plt.show()

aplicar = input("\n¿Aplicar método? (s/n): ").lower()

if aplicar == 's':
    a = float(input("Valor de a: "))
    b = float(input("Valor de b: "))

    if f(a) * f(b) > 0:
        print("No hay cambio de signo.")
    else:
        tol = 1e-6
        for i in range(100):
            c = (a + b) / 2
            if abs(b - a) < tol:
                break
            if f(a) * f(c) < 0:
                b = c
            else:
                a = c
        print(f"Raíz aproximada = {c}")
