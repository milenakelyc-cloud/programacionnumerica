Tarea 7 – Método de Regula Falsi

INTRODUCCIÓN

La resolución de ecuaciones no lineales constituye uno de los pilares fundamentales del análisis numérico. Entre los diversos métodos desarrollados para encontrar raíces de funciones, el método de Regula Falsi representa una evolución significativa del método de bisección, combinando la garantía de convergencia con una aproximación más eficiente.

Este método utiliza interpolación lineal entre dos puntos que encierran la raíz, en lugar de dividir el intervalo por la mitad. El proceso se basa en trazar una línea recta entre los puntos seleccionados y usar el punto donde esta intersecta el eje x como una nueva aproximación.

A diferencia del método de bisección, que reduce el intervalo de manera uniforme, Regula Falsi acelera el proceso al dirigir la aproximación hacia el punto donde la función cambia más rápidamente.

En este trabajo se presenta una implementación completa del método en Python, junto a fundamentos teóricos, análisis de resultados y visualización gráfica.

MARCO TEÓRICO

1. Definición y concepto

El método de Regula Falsi es un algoritmo iterativo para encontrar raíces de funciones continuas. Se basa en el teorema del valor intermedio: si f es continua en [a, b] y f(a)·f(b) < 0, entonces existe al menos una raíz en el intervalo.

2. Fórmula principal

El valor aproximado de la raíz se obtiene mediante la fórmula:

c = b - f(b)(b - a) / (f(b) - f(a))

3. Algoritmo resumido

Paso 1: Verificar que f(a)·f(b) < 0 Paso 2: Calcular c con la fórmula Paso 3: Verificar signo y redefinir intervalo Paso 4: Comprobar convergencia Paso 5: Repetir hasta tolerancia requerida

4. Interpretación geométrica

El método construye una cuerda entre los puntos (a, f(a)) y (b, f(b)). El punto donde esta línea intersecta el eje x es una aproximación más precisa que el punto medio utilizado en bisección.

5. Convergencia

El método siempre converge si existe cambio de signo, aunque la velocidad depende del comportamiento de la función. En muchos casos es más rápido que la bisección tradicional.

6. Ventajas

  • No requiere derivadas
  • Generalmente más rápido que bisección
  • Convergencia garantizada
  • Fácil implementación

7. Limitaciones

  • Puede estancarse si un extremo permanece fijo
  • Requiere cambio de signo
  • No detecta raíces múltiples automáticamente

CÓDIGO IMPLEMENTADO EN PYTHON

El siguiente código implementa el método completo, junto con la gráfica de la función y tabla iterativa: 


import numpy as np
import matplotlib.pyplot as plt

print("="*60)
print("METODO DE REGULA FALSI (Falsa Posicion)")
print("="*60)

print("\nEjemplos de funciones:")
print(" x**3 - x - 2")
print(" np.exp(x) - 3*x")
print(" x*np.sin(x) - 1")

func_str = input("\nIngrese f(x): ")
def f(x):
    return eval(func_str , {"np": np , "x": x})

a_plot = float(input("Limite inferior para grafica: "))
b_plot = float(input("Limite superior para grafica: "))

x = np.linspace(a_plot , b_plot , 500)
y = [f(xi) for xi in x]

plt.figure(figsize =(10, 6))
plt.plot(x, y, "b-", linewidth=2)
plt.axhline(0, color="black")
plt.axvline(0, color="black")
plt.grid()
plt.show()

aplicar = input("Aplicar metodo? (s/n): ")

if aplicar != "s":
    exit()

a = float(input("Extremo izquierdo [a]: "))
b = float(input("Extremo derecho [b]: "))

if f(a) * f(b) >= 0:
    print("ERROR: No hay cambio de signo")
    exit()

tol = float(input("Tolerancia: "))
max_iter = int(input("Maximo de iteraciones: "))

for i in range(max_iter):
    c = b - f(b)*(b - a)/(f(b) - f(a))
    fc = f(c)

    if abs(fc) < tol:
        break

    if f(a)*fc < 0:
        b = c
    else:
        a = c

print("Raiz aproximada: ", c)
print("f(c): ", fc)
