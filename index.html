📤 Subir archivos públicos (carpeta public/)

Arrastra y suelta aquí
o
Máx. 10 MB por archivo. Extensiones permitidas: PDF, DOC, DOCX. Los archivos se guardan en public/ de Firebase Storage.

ℹ️ Instrucciones rápidas

1) Reemplaza firebaseConfig más abajo con tu configuración de Firebase.

2) Asegúrate de aplicar las reglas de Storage para permitir lectura pública en public/ (ejemplo abajo).

3) Para eliminar archivos desde la UI necesitas reglas que permitan write (mejor: elimina desde Firebase Console o con cuenta autenticada).

4) Para publicar el sitio como Portafolio recomiendo Firebase Hosting o GitHub Pages.

⚠️ Seguridad

Evita permitir escritura pública (write) en la carpeta public/. El snippet recomendado permite lectura pública y escritura solo si el usuario está autenticado.

Reglas Storage (ejemplo)

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /public/{allPaths=**} {
      // lectura pública para archivos en public/
      allow read: if true;
      // escritura solo para usuarios autenticados (o reemplaza por tu criterio)
      allow write: if request.auth != null;
    }
    // otras reglas...
  }
}
